# Desert & Beyond FAQ concept

A VERTICAL SLICE of three FAQ questions and a correctly formed WhatsApp booking draft. It does not reproduce the complete cleanup job or change the live customer site. The city-tour amount and booking number come from the current public site and brief; the illustration is original SVG. Example wording is paraphrased for this preview. The buyer's approved full content belongs in the eventual staging work.

Reuses the existing project-owned child-theme/blueprint builder, official WordPress 7.1, PHP 8.3 and Twenty Twenty-Five 1.5 (GPL-2.0-or-later). These versions and maintenance evidence are recorded in the parent REUSE-AND-SCOPE.md. The three questions use WordPress core Details and Paragraph blocks, documented at https://wordpress.org/documentation/article/details-block/ . No separate accordion plugin or CMS is implemented. The project-specific work is styling, content, block serialization and the booking link. Native Playwright 1.60.0 (Apache-2.0) supplies headless verification.

`blueprint.json` reproduces the WordPress page. `theme.zip` contains the child theme; the page content is in the blueprint. Theme source is GPL-2.0-or-later. Source request: https://www.freelancer.com/projects/web-development/wordpress-clean-updated .
