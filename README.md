# WordPress service website examples

Three responsive portfolio demonstrations by Severian Roth. Explore at https://severianroth.github.io/service-site-examples/ . Each example includes a fast static preview, a WordPress Playground blueprint and a downloadable Twenty Twenty-Five child theme. The WordPress demo button creates an editable WordPress instance in your own browser.

- 3D Modeling Service: visual concept, portfolio filtering, structured project-brief preview.
- Alder Equipment Hire: equipment enquiry example using fictional branding.
- Northstar Client Services: intake and routing example using fictional branding.

Portfolio samples use original illustrative assets. Form previews stay in the browser. WordPress 7.1 / PHP 8.3; parent theme Twenty Twenty-Five 1.5. Theme code is GPL-2.0-or-later. See LICENSE and REUSE-AND-SCOPE.md for provenance.

Additional nonprofit examples: [Welter homepage concept](https://severianroth.github.io/service-site-examples/welter/) and [Open Table volunteer site](https://severianroth.github.io/service-site-examples/community-kitchen/). Both include editable WordPress versions.
