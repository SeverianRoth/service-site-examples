What should I include in a project enquiry?

The intended use, approximate number of models or views, reference material, preferred file formats and your timing. The project brief above helps organize this.

Can a model serve more than one purpose?

It can, but a model for product marketing and one for manufacturing may need different geometry and output formats. Discuss the intended uses together when scoping the work.
