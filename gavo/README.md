# Gavo landing-page concept

Original small design sample by Severian Roth, 8 September 2026. Danish draft copy, generic gift-card illustrations, App Store call to action and a three-step explanation. The card overview is an illustration with sample data; it is not a screenshot of Gavo or a count of actual Gavo users/cards. Add/reset changes the illustrated total from two cards/500 kr. to three cards/750 kr.

Product facts were checked against the [Gavo App Store listing](https://apps.apple.com/dk/app/gavo/id6758522342). Balance and expiry information are entered manually. Brand assets, the existing counter and final Danish copy can be incorporated from the buyer's supplied materials.

This frontend adapts original responsive layout patterns from the existing author sample at `2fcad188e32001a5595b7191367bfcd847df68ed`. Native HTML/CSS/DOM and `Intl.NumberFormat` are sufficient; no third-party code, screenshots or assets are bundled. Original sample source is MIT licensed. Gavo's name belongs to its owner.

Open `index.html` directly or serve the folder with a static HTTP server. The download contains the HTML, CSS, JavaScript and this note. Existing editable WordPress examples are linked separately; this introductory concept does not claim a completed WordPress migration.
