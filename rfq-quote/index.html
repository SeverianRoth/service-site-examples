What was built

A local Python adapter processes one synthetic PDF layout and two supplied CSV files, then writes a real XLSX draft. pypdf handles extraction; openpyxl handles the workbook. Source includes exact dependency versions and the declared matching assumptions.

This demonstrates the PDF/catalogue/Excel core. The proposed n8n workflow is a separate next step. The sample does not include OCR, ERP access, automatic sending or a deployed service.

Verified with real files

Eleven checks passed on Windows with Python 3.13.7, pypdf 6.18.0 and openpyxl 3.1.5. The checks extract both PDFs, validate matching decisions and read the written Excel workbook back.

A second PDF changes the quantities and contains two resolvable lines. It yields a draft total of $50.75, independently of the first file.

  • An RFQ-supplied price cannot replace the approved list

  • Non-finite, negative and over-precision prices require review
