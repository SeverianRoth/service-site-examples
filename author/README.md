# Author website example

Original responsive WordPress page with two book presentations, keyboard-accessible sample-chapter dialogs, an author section, and a newsletter form preview. Author, books, cover artwork and sample copy are fictional portfolio content. The form performs browser validation and displays a local preview; it does not subscribe anyone or send messages.

Reuses this repository's existing WordPress child-theme builder, Twenty Twenty-Five **1.5** (GPLv2 or later), and the official WordPress Playground blueprint runtime, pinned to WordPress **7.1** and PHP **8.3**. The established theme and runtime handle installation, editing and rendering. Page layout, original CSS cover artwork and chapter interactions are project-specific. Browser-native dialog and email validation avoid extra dependencies. A production newsletter connection uses the buyer's existing mailing provider after scope and access are agreed.

`theme.zip` is the installable child theme and contains the source. `blueprint.json` reproduces the editable WordPress example. Theme source is supplied under GPLv2 or later.
